# X 配文

最近用 Codex 给这只三花猫做了 16 张动态表情，整套效果放在 GIF 里了。

配字选的都是聊天时用得上的：「收到喵」「你继续说」「猫生艰难」「本喵下班」……尤其是那张「你继续说」，猫一脸无语，配上抱着胳膊的动作，意思就很到位。

做的时候发现，图片好看只是第一步。九宫格切成动画，猫会左右晃；每帧各画各的，字牌也会跟着动。还有一张歪头的，合成之后耳尖被截掉了一点，只能单独重做。

后来把角色参考、固定字牌、身体对齐这些步骤整理了一遍，也把中断后接着做、哪张不好就单独修的流程留下了。现在做完能拿到透明 GIF、封面、缩略图和打包文件，源图和提示词也都在。

顺手整理成了一个 Codex skill，叫「表情工坊 / Sticker Studio」。用的是 Codex 内置生图，没有另接模型接口。

想试的话，装好后告诉它你想做什么角色，先看人设和 16 张动作配字表，确认了再开始生成。仓库里放了安装方法和这套三花猫的效果：

https://github.com/dogpowerful/sticker-studio-skill
